# CCOnklusyon Registration & Check-in System — Agent Rules

Canonical, tool-agnostic project rules (the [agents.md](https://agents.md) convention) for any AI
coding agent working in this repo. `CLAUDE.md` is a thin pointer to this file — edit here, not there.

Source of truth: the MVP spec + SDLC docs handed off Sept 13, 2026 (Google Docs, linked below).
This file exists so those don't need re-explaining every session. Default to the spec; deviate
only where the *real, live* data or infra forces it — and record the deviation in `CHANGES.md`
when it happens.

## Non-negotiables (from spec, do not violate)
- **Zero-Build Mandate:** single-file HTML/JS/CSS only. No Webpack/Vite/npm build pipelines.
- **Zero incremental budget:** Google Workspace, Apps Script, Sheets, GitHub Pages, Telegram Bot API,
  QuickChart/qrserver CDN only. No paid services.
- **Concurrency:** every Sheet cell write in `doPost` wrapped in `LockService.getScriptLock()`,
  10s wait window.
- **Latency target:** sub-3s door triage cycle (scan → confirmation).
- **VIP alert:** Telegram notification within 3s of a VIP check-in.
- **Tier colors:** Gold `#B8860B` for VIP Pass, Royal Blue `#1A56DB` for Regular Attendee.
- **Duplicate scans:** must be atomically blocked, never double-counted.

## API contract (per spec — do not change field names/shapes without updating this file)
- `POST /api/checkin` — `{action:"checkin", attendance_code, device_id}` → `SUCCESS` \| `DUPLICATE` \| `NOT_FOUND`
- `POST /api/sync` — `{action:"sync", items:[...]}` — bulk offline-queue flush
- `GET /api/recent?limit=N` — `{action:"recent"}` — feeds the projector wall

## Apps Script gotcha (worth remembering)
Any top-level function named with a trailing underscore (e.g. `handleCheckin_`) is treated as
**private by convention** and is hidden from the editor's Run-function dropdown. Entry points meant
to be run manually from the editor (like `generateCredentials`) must NOT have a trailing underscore.
Internal helpers keep the underscore on purpose (signals "don't call this manually").
