## How to verify a redeploy
1. Apps Script editor → paste the whole of `apps-script/Code.gs` → **save (Ctrl+S)**.
2. **Deploy → Manage deployments** → the pencil on the **existing** deployment whose URL ends in `…VPi/exec` → Version: **New version** → Deploy.
   "+ New deployment" creates a *different URL* that the scanner and wall don't use.
3. In a browser open that same URL with `?action=ping` — it must answer `{"status":"SUCCESS","message":"pong",…}`.
   If it still says "Unknown action.", the running version is old. If you did create a new URL, send it and both HTML files get updated.
